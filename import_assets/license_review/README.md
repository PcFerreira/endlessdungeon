# Pack requiring license review

[Forest Isometric Pixel Art](isometric_pixel_forest/) by Kipperfalcon was downloaded from its [publisher page](https://opengameart.org/content/free-forest-isometric-pixel-art). The page declares CC0. The bundled `Forest Isometric Pack Free/README.txt` also labels the pack CC0, but says:

> You may not redistribute, resell, or repackage the assets

It extends that restriction to modified or unmodified standalone content and asset collections. These statements conflict with the standard CC0 terms. The downloaded files, original README and saved publisher page are preserved here. This pack is excluded from the main collection's license counts and attribution catalog pending publisher clarification.

`SOURCE.json` records the conflict and download hash. `LICENSE_SOURCE.md` describes the review status. A copy of the standard CC0 text is retained for comparison; its presence does not resolve the conflicting publisher instructions.
