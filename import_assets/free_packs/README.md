## Licenses and provenance

Each pack includes `SOURCE.json` with its creator, publisher URL, license, downloaded file hashes and credit text. `LICENSE_SOURCE.md` explains the source of the license declaration. Original license files are preserved, and a full copy of the applicable standard license is also stored inside each pack and in `licenses/`.

Use [ATTRIBUTION.md](ATTRIBUTION.md) for the required credits. [manifest.json](manifest.json) contains the complete pack list. Existing assets elsewhere in `import_assets/` are outside this new catalog and keep their existing terms.

One additional forest pack is preserved in [license_review](../license_review/README.md). Its source page declares CC0, but its bundled README prohibits redistribution. It is outside the cleared collection until the publisher resolves those conflicting statements.

## Godot adoption

This is the project's staging folder. Its parent `.gdignore` remains in place. Copy chosen assets into `assets/` with their dependencies, license and attribution when adopting them. Keep glTF `.bin` files and texture paths together; prefer GLB/glTF over FBX for the included 3D packs.

The current game renders a 3D world. Isometric PNG sheets need tile slicing and a 2D tile map or Sprite3D presentation. Their projection angles, palettes and sizes differ across packs. Character sheets need frame/direction mappings. Blender loot needs an export step, and `.vox` files need conversion before Godot use.

## Checks and limits

ZIP CRC checks passed. Cube World mirror files were checked against a pinned Git revision and their Git blob hashes; the publisher's Google Drive returned a quota error. The original 427 glTF/GLB files passed JSON/header, buffer and external dependency checks. The original 290 OGG/MP3 files had recognized audio streams and positive durations in ffprobe.

[model_inventory.json](model_inventory.json) lists model meshes, skins and animation names. [audio_inventory.json](audio_inventory.json) lists audio durations and codecs. [voxel_inventory.json](voxel_inventory.json) distinguishes the nine modern MagicaVoxel files from the 12 legacy dense-grid files. [validation.json](validation.json) records the completed checks.

The seven item-variety additions passed a separate Godot import and resource check: 231 models instantiated and 659 PNG/SVG textures loaded, with no reported errors or warnings. [item_variety_validation.json](item_variety_validation.json) records that batch's check and license counts; its logs are in `validation/`.

The fourteen world expansion additions passed a further check: 837 models instantiated, 2086 textures loaded and 24 Godot-compatible audio streams loaded, with no reported errors or warnings. All 34 original/derived audio files passed codec/duration checks, and the ten FLAC/WAV pairs had identical decoded PCM. The combined model inventory now contains 1495 GLB/glTF files. [world_expansion_validation.json](world_expansion_validation.json) records the latest check and catalog license counts. [world_model_inventory.json](world_model_inventory.json) and [world_audio_inventory.json](world_audio_inventory.json) describe the new batch.

The extra padadu fantasy pack is partial: nine of 17 uploads downloaded before itch.io returned HTTP 429. `padadu_fantasy_voxels/SOURCE.json` lists the eight missing uploads. The staged files are intact.

Godot 4.7.2 imported the original 25-pack collection in an isolated temporary project. The resource check instantiated its 427 models and loaded 2750 textures and 290 audio streams. The texture count includes images extracted from models by Godot. Logs and the check script are saved in `validation/`. Visual style matching, scale, collisions, character attachment points, animation blending, audio loudness and loop behavior still need review when assets are adopted. The RPG audio preview contains a malformed vendor metadata comment; it imports and loads with a warning, and the original is preserved.
