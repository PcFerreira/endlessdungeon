# Asset attribution

These entries cover the packs in this collection that require attribution. Copy the entries for assets actually used into the shipped game credits and retain their license text. If you modify an asset, add a description of the change.

- Isometric 64x64 Medieval Building Tileset by Seth Galbraith. Source: https://opengameart.org/content/isometric-64x64-medieval-building-tileset. License: CC-BY-3.0 (https://creativecommons.org/licenses/by/3.0/). Houses inspired by Clint Bellanger's Medieval Building Tiles; designed to accompany Yar's outside tiles.

The other packs use CC0. Their creator/source records and optional credit text are in each `SOURCE.json` and `LICENSE_SOURCE.md`. Original publisher license files remain beside their assets. The existing packs outside `free_packs/` retain their existing licenses and attribution requirements.
