# Endless World voxel town pack

44 exported models cover eight themes: forty original house/workshop/gate/market/civic pieces and four KayKit Halloween/Kenney Holiday voxel derivatives. Each model has a self-contained Godot `.scn` and a portable `.glb`.

Read [catalog.json](catalog.json) for paths, dimensions, doorway sockets, triangle counts, hashes and provenance. The game selects these models for eight themed procedural town series. [Runtime companions](runtime/) add actual faceted versions and eight goods-free market frames; their selection and fitting are described in the [integration guide](../../docs/TOWN_VOXEL_ASSETS.md).

Axes: +Y up, +Z front, bottom-centered origin. Original pitch: .125 units. Vertex colors provide materials without external textures. Structural scenes include no gameplay scripts or collision nodes.

The original forty models were authored for this project; no separate original-asset license is introduced here. The four source derivatives retain recorded CC0 provenance and the exact notices in [licenses/KayKit-Halloween.txt](licenses/KayKit-Halloween.txt) and [licenses/Kenney-Holiday.txt](licenses/Kenney-Holiday.txt). Source files under `import_assets` remain unchanged.
