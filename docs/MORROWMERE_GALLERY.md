# Morrowmere native gallery

`tools/capture_dimension.gd` renders the actual native Game through the Sanctum, Lanternwake and the finite dimension. It reads the current dimension catalogue rather than a fixed list of destinations. Run headed Godot after the coordinated native reader window is released:

```sh
./godot.sh --script tools/capture_dimension.gd -- \
  --site-views --population-views \
  --output=res://artifacts/morrowmere-expanded
```

The base gallery contains the portal route, arrival, initial and observed atlases, opposing cameras at every named area, and coast/river/lake/hill views when those fields exist. `--site-views` adds each authored destination and two atlas views proving hovered and selected destination names. `--population-views` adds one actual resident conversation and one live authored encounter per area. The current eight-area, 56-site recipe produces 101 frames with both options. Omitting both options retains the smaller terrain and portal gallery. `--output` keeps earlier accepted evidence separate.

Each PNG comes from Godot's actual viewport. `native-gallery.json` records the exact definition, map/content revisions, site count, active options and frame positions/states/chunk counts. Destination frames record the real site identity, kind and name. Conversation frames record the actual speaker and dialogue text. Creature records retain the live enemy ID, catalogue species, health and authored encounter namespace. The helper asserts that selected encounter creatures have actual scene-tree nodes. It waits for the real renderer warmup, preserves the intended camera after warmup restoration and asserts that Game removed the loading overlay. Camera size and readiness are recorded for every image. Before/after hashes cover the Game, finite provider, terrain/construction/population/map/rendering scripts, construction/runtime palettes and dimension definitions. A changed input rejects the run after private-save cleanup.

The helper mutes its own audio bus, disables physics during images, uses a private temporary save directory and removes its saves afterward. These views verify presentation and real interaction wiring. Ordinary walking, combat, loot, defeat persistence, disk reload and historical Journey return belong to the focused population/travel fixtures. Wide terrain views can expose streamed-window corners and do not establish frame pacing or complete camera coverage.

The finite atlas fixture is `tests/test_dimension_map.gd`. It checks complete topology without extra chunks or discovery promotion, bounded edge sampling, stable caches, ordinary endless/online map separation and actual discovery/selection for villages, graveyards and remote houses. Rendered destination markers remain discovery-dependent even though the atlas shows the authored terrain. The finite atlas keeps all eight area names and known markers; individual destination names appear for the hovered marker or selected waypoint. Hover and mouse exit preserve the terrain texture, and changing context discards the previous hover.

The terrain raster comes from `tools/export_dimension_map.gd`; the standalone SVG comes from `tools/draw_dimension_map.rb`. The drawing helper rejects a raster definition that differs from the current recipe. Existing licensed assets and their notices remain in the project's asset attribution files. These local native tools do not update the deployed browser pack or persistent server.
